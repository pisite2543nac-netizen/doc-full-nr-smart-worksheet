DOC-FULL-NR - GitHub Pages Gateway Setup
========================================

เป้าหมาย
- GitHub Repository = Source Code / Backup / Version Control
- Firebase Hosting = เว็บใช้งานจริง
- GitHub Pages URL = ทางเข้า/Redirect ไปเว็บจริง เพื่อไม่ให้หน้าขาว

หลังอัปโหลดชุดนี้ขึ้น GitHub แล้ว:
1) เปิด Repository: doc-full-nr-smart-worksheet
2) Settings > Pages
3) Build and deployment
4) Source = Deploy from a branch
5) Branch = main
6) Folder = /docs
7) Save
8) รอประมาณ 1-3 นาที
9) เปิด:
   https://pisite2543nac-netizen.github.io/doc-full-nr-smart-worksheet/

ลิงก์ GitHub Pages จะพาไป:
https://doc-full-nr.web.app/

เหตุผลที่แนะนำวิธีนี้
- ไม่ต้องเก็บ .env.local หรือ Firebase config เพิ่มบน GitHub
- ไม่ต้องมี Hosting ซ้ำสองระบบ
- Firebase Authentication / Firestore / SPA Routing ทำงานจาก Hosting ที่ออกแบบไว้
- ทำระบบให้เสร็จเร็วกว่าและลดจุดผิดพลาด
