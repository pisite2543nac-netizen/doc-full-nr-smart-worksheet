EASIEST UPLOAD METHOD
---------------------
1. Extract this ZIP to a normal folder.
2. Open the extracted folder.
3. Double-click:
   00_PUSH_TO_GITHUB.bat
4. A list of files to be uploaded will appear.
5. Confirm that these are NOT listed:
   .env.local
   node_modules
   dist
   firebase-adminsdk JSON
   serviceAccountKey.json
6. Press any key.
7. Wait for:
   GITHUB PUSH SUCCESS

The repository URL is already configured in the script.
